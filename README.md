# Saifuddin Mondal — React Portfolio

A responsive React + Vite portfolio inspired by the supplied dark glassmorphism reference.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
The production output is generated in `dist/`.

## Deploy to Vercel
1. Push this project folder to a GitHub repository.
2. Import the repository in Vercel.
3. Framework preset: **Vite**.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Click Deploy.

## Personalize before publishing
Edit `src/App.jsx`:
- Set `profile.email`, `profile.github`, and `profile.linkedin` to your real public links.
- Add your CV PDF as `public/Saifuddin-Mondal-CV.pdf` (create the `public` folder).
- Update project descriptions and replace the placeholder project discussion links with live demo/repository URLs.
- The contact form currently uses `mailto:`. For direct website form submissions, connect a form provider or backend.

This project uses React, Vite, Tailwind CSS, Lucide React icons, and custom CSS for the reference-matched layout.
